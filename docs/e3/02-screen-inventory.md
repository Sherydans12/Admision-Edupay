# E3 — Inventario de pantallas P0

## Control y leyenda

El inventario cubre las 22 capacidades P0 del [backlog funcional](../e1/14-mvp-backlog.md#p0--recorrido-mínimo-completo). Los IDs `SCR-FAM`, `SCR-STAFF` y `SCR-ADM` son estables para el prototipo y futuras pruebas; no son rutas técnicas ni nombres de componentes.

- **Estados:** estado de negocio y feedback técnico se documentan separados.
- **Permisos:** una acción oculta no sustituye autorización server-side.
- **Responsive priority:** `M1` móvil primero, `D1` escritorio primero, `T1` tablet funcional.
- **Datos:** todos los ejemplos de prototipo son sintéticos.
